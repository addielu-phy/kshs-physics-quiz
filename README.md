# 高二物理自學評量網頁（雄中 高二下期末）

學生可登錄姓名、線上作答整份試卷，系統會**自動評分**、做**錯題與單元分析並附詳解**，並支援**第二次、第三次練習**（含「只練我的錯題」）。成績紀錄存在使用者的瀏覽器（localStorage），可離線使用。

- 本卷：**高雄中學 113 學年度第 2 學期 高二物理 第三次段考（期末考）**，共 24 題、滿分 100。
  - 單選題 20 題（每題 4 分，A–E 五選項）
  - 多選題 4 題（每題 5 分，**分科型部分給分**：每選項各自判定，答對 +、答錯倒扣，最低 0 分）
- 範圍：圓周運動、功與能量、動量與碰撞、萬有引力與衛星、理想氣體與氣體動力論。
- 題目來源：高雄中學物理科公開歷屆試題，僅供同學自學練習使用。

## 兩種練習模式
- ⚡ **隨手練習**：一題一題作答，選完立刻看對錯、答錯馬上跳詳解，題目隨機洗牌。
- 📝 **正式測驗**：整卷作答 → 評分 → 單元診斷 ＋ 逐題詳解 ＋ 與歷次比較。
- 🎯 **只練錯題**：針對上次做錯的題目加強。

## 檔案結構
- `index.html`：頁面外殼
- `style.css`：深色／淺色主題樣式（右下角 🎨 可切換）
- `data.js`：題庫（題目、選項、正解、配分、單元分類、詳解）
- `app.js`：登錄／作答／評分／分析／重複練習邏輯（支援 A–E 五選項、單選＋多選、每題配分）
- `assets/`：各題附圖（自試卷擷取）
- `teacher.html` / `teacher.js` / `firebase-config.js`：選配的老師端集中收成績（預設未啟用）

## 更換 / 新增題目
編輯 `data.js` 中的 `QUESTIONS` 陣列後重新 push 即可。每題欄位：
- `id` 題號、`u` 單元、`s` 題幹（可用 HTML：`<sub>`/`<sup>`/`√`）、`o` 選項陣列、`e` 詳解、`img` 附圖、`p` 配分。
- 單選題：`a` 為正解索引（0=A）。
- 多選題：加 `multi:true`，`a` 為正解索引陣列（例 `[0,2,4]`）。計分為分科型部分給分（每選項各自判定，答對 +、答錯倒扣，最低 0）。
